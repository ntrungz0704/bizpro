## Brand & Style

### Brand Narrative
BizPro+ is an enterprise-grade operational operating system engineered specifically for Vietnamese enterprises, founded on the premise: *"Một nền tảng. Toàn bộ vận hành doanh nghiệp."* (One platform. Total enterprise operations).

The design language moves deliberately away from decorative, generic SaaS conventions and ungrounded AI mockups. Instead, it adopts the disciplined, engineering-first authority of Stripe, Ramp, and Linear. The system projects rigorous operational capability across high-density workflows: Kho hàng (Inventory), Quản lý Đơn hàng (Order Operations), CRM (Client & Pipeline Management), and HRM (Human Resources & Payroll).

### Aesthetic Style
- **Corporate Modern & Hyper-Refined Editorial:** Built on clean geometric foundations, stark micro-contrast, structural grid discipline, and strict visual density.
- **Surface Integrity:** Interfaces prioritize information clarity via subtle hairline dividers (`#E2E8F0`), high-contrast slate typography (`#0F172A`), and functional accent colors that guide rapid business decision-making.
- **Emotional Stance:** Authoritative, razor-sharp, stable, and deeply focused. It gives founders, COOs, and operations managers the confidence of an institutional financial platform.

## Colors

The color palette pairs an electric operational primary blue with dense executive navies and balanced slate neutrals. This balances dense data tables and clear visual hierarchy.

### Primary Scale
- **Primary Base (`#2563EB`):** High-intent calls-to-action, active indicators, selected states, and primary navigation focus.
- **Primary Hover (`#1D4ED8`):** Direct interactive hover state for primary triggers.
- **Primary Dark (`#1E40AF`):** Active pressed states, focused borders, and high-emphasis links.
- **Primary Light (`#DBEAFE`):** Selection badges, active sidebar pill backgrounds, and table row selections.
- **Primary Subtle (`#EFF6FF`):** Tinted cards, contextual notices, and bulk operation banners.

### Dark Navy Foundation
- **Navy 900 (`#0B1220`):** Dark-mode canvases, primary navigation bars, high-contrast metric callout cards, and structural shell headers.
- **Navy 800 (`#111C32`):** Elevated dark panels, secondary toolbars, and contextual dark dropdown menus.
- **Navy 700 (`#1E293B`):** Dark surface borders, dividers within dark panels, and disabled states in inverted contexts.

### Neutral System
- **Background Primary (`#FFFFFF`):** Main application canvas, table surfaces, form inputs, and modal backgrounds.
- **Background Secondary (`#F8FAFC`):** Table headers, sub-navigation panels, inactive workspace areas, and structural sidebars.
- **Background Tertiary (`#F1F5F9`):** Input field fills, skeleton loaders, and nested sub-component card backgrounds.
- **Border (`#E2E8F0`):** Crisp 1px container dividers, grid boundaries, and component strokes.
- **Text Primary (`#0F172A`):** Core data points, headers, high-contrast labels, and status titles.
- **Text Secondary (`#475569`):** Body paragraphs, contextual table metadata, and active label text.
- **Text Muted (`#64748B`):** Placeholder labels, disabled states, column sorting icons, and secondary timestamps.

### Semantic Accents
- **Success (`#16A34A`):** Inventory stocked, paid invoice, approved leave request, positive delta revenue.
- **Warning (`#D97706`):** Low inventory alerts, impending delivery SLA, awaiting tax clearance.
- **Error (`#DC2626`):** Canceled order, critical inventory deficit, sync error, destructive triggers.
- **Info (`#0284C7`):** Transit status, API sync notes, informational metric tags.
- **Purple (`#7C3AED`):** Cross-enterprise automations, AI/ML forecast indicators, and specialized payroll tiers.

## Typography

The typography leverages **Inter** across all application touchpoints. Built for high clarity in complex operational interfaces, it supports dense Vietnamese tone-mark sets without vertical clipping or awkward baseline shifts.

### Hierarchy & Rules
- **Display & Large Headlines (56px, 40px):** Reserved for high-level executive dashboards, primary module launch screens, and performance overviews. Kerning is locked to tight negative tracking (`-0.03em` to `-0.025em`) to evoke editorial precision.
- **Section Headers (24px, 20px):** Form section dividers, drawer panels, and primary table group titles.
- **Body Architecture (16px, 14px):** `body-lg` serves as the primary reading and form narrative size. `body-md` is the workhorse token for data grids, dense CRM contact rows, inventory item listings, and HRM employee record cards.
- **Data & Label Tokens (13px, 12px, 11px):** High-density labels, micro-tags, table column headers, and metric trend indicators. Tabular numerals (`font-feature-settings: "tnum" 1`) must be enabled on all financial, currency (VND), and inventory counts.

## Layout & Spacing

BizPro+ enforces an 8pt layout grid, with a strict 4pt baseline for dense components (micro-pills, compact table cells, metric badges).

### Grid Strategy
- **Desktop (>= 1280px):** 12-column fluid grid, 24px gutters, fixed 256px operational sidebar. Content spans 12 columns for enterprise multi-pane views (e.g., 3-col master-detail views: 3-column list, 6-column detail, 3-column activity feed).
- **Tablet (768px - 1279px):** 8-column layout, 16px gutters, collapsed navigation rail (64px width).
- **Mobile (< 768px):** 4-column layout, 16px margins, single-column stacked hierarchy. Complex tables collapse into structured operational cards.

### Spacing Tokens
- `space-xs` (4px): Icon-to-text spacing within buttons, inner status dot gaps.
- `space-sm` (8px): Input padding (vertical), badge margins, compact button horizontal margins.
- `space-md` (12px): Standard field spacing within forms, list item gap in dense sidebars.
- `space-lg` (16px): Standard container padding, card header-to-body margin.
- `space-xl` (24px): Primary section separator, card internal padding for executive panels.

## Elevation & Depth

BizPro+ relies on crisp micro-borders and soft ambient shadows to create depth, avoiding heavy drop shadows.

### Elevation Levels
- **Layer 0 (Canvas):** `#FFFFFF` (Primary working space) or `#F8FAFC` (Module background). No elevation.
- **Layer 1 (Cards, Data Panels, Table Shells):** 
  - Background: `#FFFFFF`
  - Border: 1px solid `#E2E8F0`
  - Shadow: `0px 1px 3px 0px rgba(15, 23, 42, 0.04), 0px 1px 2px -1px rgba(15, 23, 42, 0.02)`
- **Layer 2 (Dropdowns, Floating Toolbars, Active Filters):** 
  - Background: `#FFFFFF`
  - Border: 1px solid `#E2E8F0`
  - Shadow: `0px 4px 6px -1px rgba(15, 23, 42, 0.07), 0px 2px 4px -2px rgba(15, 23, 42, 0.04)`
- **Layer 3 (Modals, Slide-over Drawers, Batch Process Overlays):** 
  - Background: `#FFFFFF`
  - Border: 1px solid `#E2E8F0`
  - Backdrop: `rgba(11, 18, 32, 0.45)` with `backdrop-filter: blur(4px)`
  - Shadow: `0px 20px 25px -5px rgba(15, 23, 42, 0.1), 0px 8px 10px -6px rgba(15, 23, 42, 0.05)`

### High-Contrast Outlines & Dark Contrast Blocks
High-priority visual zones (e.g., Enterprise KPI highlight tiles) can use an inverted Layer 1 surface: Background `#0B1220`, border 1px solid `#1E293B`, with white high-contrast text. This creates clear visual anchors on executive summary dashboards.

## Shapes

The design system uses deliberate, disciplined corner radii to maintain a modern, technical feel:

- **Inputs, Buttons, Compact Badges:** 8px (`rounded-md` equivalent) to retain structured geometry.
- **Cards, Table Containers, Form Sections:** 12px to 16px (`rounded-lg` to `rounded-xl`) to clearly group complex workflows.
- **Modals & Flyout Sheets:** 16px (`rounded-xl`) on all visible corners.
- **Pills / Status Chips:** Full pill radius (`9999px`) used only for binary status tags (e.g., "Đã thanh toán", "Đang vận chuyển", "Đã chốt ca").

## Components

### Buttons
- **Primary:** Background `#2563EB`, text `#FFFFFF`, radius 8px, padding 8px 16px (`font-size: 14px; font-weight: 500`). Hover: `#1D4ED8`. Active: `#1E40AF`. Focused: 2px ring `#DBEAFE` with `#2563EB` offset.
- **Secondary (Outlined):** Background `#FFFFFF`, border 1px solid `#E2E8F0`, text `#0F172A`. Hover: `#F8FAFC`, border `#CBD5E1`.
- **Tertiary (Ghost):** Background transparent, text `#475569`. Hover: Background `#F1F5F9`, text `#0F172A`.
- **Destructive:** Background `#DC2626`, text `#FFFFFF`. Hover: `#B91C1C`.

### Form Inputs & Selectors
- **Text Inputs / Number Inputs (VND / Units):** Height 40px, background `#FFFFFF`, border 1px solid `#E2E8F0`, radius 8px, padding 8px 12px. Placeholder: `#64748B`. Focus: Border `#2563EB`, box-shadow `0 0 0 1px #2563EB`. Currency fields display a right-aligned fixed suffix (`₫` / `VND`) in `#64748B`.
- **Labels:** `label-md` (13px, weight 500, `#0F172A`), stacked 6px above the field.

### Data Tables (Kho Hàng, Đơn Hàng, HRM)
- **Container:** Rounded 12px, border 1px solid `#E2E8F0`, background `#FFFFFF`, overflow hidden.
- **Header Row:** Background `#F8FAFC`, border-bottom 1px solid `#E2E8F0`, height 40px, text uppercase `label-sm` (12px, weight 600, `#475569`).
- **Data Rows:** Height 48px (compact) or 64px (rich data), border-bottom 1px solid `#F1F5F9`. Hover: Background `#F8FAFC`. Selected: Background `#EFF6FF`, border-bottom 1px solid `#DBEAFE`.
- **Numerical Alignment:** Monospaced tabular figures (`tnum`), right-aligned for monetary values, inventory balance, and metric percentages.

### Status Badges & Chips
- **Semantic Pills:** Radius 9999px, padding 2px 10px, typography `label-sm` (12px, weight 600).
  - *Đã duyệt / Sẵn sàng (Success):* Background `#DCFCE7`, text `#15803D`, border 1px solid `#BBF7D0`.
  - *Chờ duyệt / Cảnh báo (Warning):* Background `#FEF3C7`, text `#B45309`, border 1px solid `#FDE68A`.
  - *Lỗi / Đã hủy (Error):* Background `#FEE2E2`, text `#B91C1C`, border 1px solid `#FECACA`.
  - *Đang xử lý (Info):* Background `#E0F2FE`, text `#0369A1`, border 1px solid `#BAE6FD`.

### Cards & Workflow Containers
- **Metric KPI Card:** Background `#FFFFFF`, border 1px solid `#E2E8F0`, radius 12px, padding 20px. Contains top label (`label-md`, `#475569`), value block (`headline-md`, 24px, `#0F172A`), and bottom trend pill (`+12.5% vs tháng trước`).
- **Executive Dark Card:** Background `#0B1220`, border 1px solid `#1E293B`, radius 16px, padding 24px. High-value data display with white typography and Primary Light accents.

### Checkboxes & Radios
- Size 16px by 16px, radius 4px (checkbox) or 50% (radio), border 1.5px solid `#CBD5E1`. Checked state: Background `#2563EB`, border `#2563EB`, icon white checkmark.
